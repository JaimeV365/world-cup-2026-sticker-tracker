⚙ Data & look

Auto-save: your collection is stored in this browser whenever you change it. It survives refresh and reopening the file on the same device/browser.

Tip: periodically click Export backup and keep the JSON somewhere safe. The file is a full snapshot — missing stickers, spare counts, postal swaps (open/completed, sent/expected lines, pending/received/written-off), and dark/bright mode. Import restores everything on another device or after clearing browser data.

Flags load from the internet when available; if you’re offline they fall back to emoji (or a star for special stickers).
